公司 HAPI Nexus 使用指南

这是一份面向公司内部同事的使用教程。无论你是否会写代码，都可以用 HAPI Nexus 在浏览器、电脑桌面应用或手机上使用公司内部的 AI 编程助手：远程查看任务进度、继续对话、批准操作、同步 Codex 历史，并和项目成员共享会话。

1. HAPI Nexus 是什么

一句话理解：HAPI Nexus 是公司内部的 AI 编程助手工作台。你可以在网页、桌面或手机上，把一个代码任务交给 AI 助手执行，并随时查看进度、继续提问、审批操作或把结果分享给同事。

它不是一个普通聊天机器人，而是连接你的项目代码目录、AI 编程工具和团队协作的统一入口。只要你的电脑 Runner 已注册到平台，Web 端就可以在你授权的目录中创建项目和会话。

它是什么

一个集中管理 AI 编程任务的 Web 平台。它可以连接 Claude Code、OpenAI Codex CLI、Cursor Agent、Grok Build、OpenCode 等工具，让你用统一界面启动和管理 AI 会话。

为什么要用

不用一直守在终端前。你可以在浏览器或手机上查看 AI 是否卡住、是否需要批准命令、是否已经完成修改，也可以把会话和项目上下文分享给团队成员。

什么时候会用

需要 AI 帮你读代码、改 Bug、写功能、解释报错、生成测试、整理文档、同步 Codex 本地历史，或需要同事一起查看某个 AI 任务过程时，都可以使用。

关系说明：HAPI 服务器是中心；你的电脑通过客户端 hapi 注册为机器并提供可用目录；Web 和手机只是聊天与审批入口；项目分享给其他用户后，对方通过服务器查看共享项目和会话，不会直接连接或控制你的电脑。
最常见的使用场景：在公司电脑上启动 Runner 注册机器，然后在 Web 里选择项目和目录，新建一个 AI 会话；离开电脑后，用手机继续查看进度和审批操作。

2. 使用流程图

普通用户的核心流程是：登录 Web → 获取个人 token 并安装客户端 → 启动 Runner 注册机器 → 创建或选择项目 → 选择目录 → 创建会话 → 与 AI 对话和协作。没有注册机器时，无法新建项目或新建对话。

3. 登录公司 HAPI Web 与首次准备

第一次使用 HAPI Nexus 时，请按下面顺序完成。

  1. 申请账号：向平台管理员或团队负责人申请公司 HAPI Nexus 账号，获取初始用户名和密码。
  2. 登录网页：打开 https://hapi.xthings.services，使用用户名和密码登录。第一次登录后，请先进入右上角头像菜单或 Settings -> Account 修改密码。
  3. 获取个人专属 access token：在 Settings -> Account 中复制你的个人 access token。这个 token 只属于你本人，请不要发给其他人。
  4. 安装客户端：如果你需要连接自己的电脑或同步本地 Codex 会话，请安装客户端 hapi，并用上一步的个人 access token 完成初始化。
提示：如果你只是在 Web 上查看别人分享的项目，可以先完成账号申请、网页登录和修改密码；如果要让平台使用你电脑上的代码目录，再继续完成 access token 和客户端安装。
请勿分享你的个人 access token。它相当于客户端接入平台的个人凭据。如果怀疑泄露，请在账号设置里重新生成。

4. 安装客户端 hapi

如果你只在 Web 上查看或参与共享项目，通常不需要安装客户端。只有当你希望 HAPI 使用你自己电脑上的代码目录时，才需要安装客户端并启动 Runner。

官方下载地址：https://github.com/jacobs-256/hapi-nexus/releases。请根据自己的电脑平台选择合适的客户端程序，例如 macOS Apple Silicon、Linux ARM64、Linux AMD64 或 Windows。
不要下载带 -server 的包。带 -server 的文件是服务器端程序，用于部署 HAPI 服务；普通用户电脑上安装客户端时，请下载不带 -server 的 hapi 客户端包。

macOS 安装

推荐：Homebrew

brew install jacobs-256/hapi-nexus/hapi
hapi --version

手动下载

# 从 https://github.com/jacobs-256/hapi-nexus/releases 下载匹配 macOS 平台的 hapi 客户端压缩包
# 注意：不要下载文件名带 -server 的包
xattr -dr com.apple.quarantine ./hapi
chmod +x ./hapi
sudo mv ./hapi /usr/local/bin/hapi
hapi --version
如果 macOS 提示“hapi 已损坏，无法打开”：这是系统对下载文件的安全隔离提示，通常执行上面的 xattr 命令即可。

Linux 安装

# 从 Releases 下载 linux-arm64 或 linux-amd64 对应版本
# 注意：不要下载文件名带 -server 的包
chmod +x ./hapi
sudo mv ./hapi /usr/local/bin/hapi
hapi --version

Windows 安装

# 从 Releases 下载 Windows 对应版本；不要下载文件名带 -server 的包
# PowerShell 进入解压目录
.\hapi.exe --version

建议把 hapi.exe 放在固定目录，例如 C:\Tools\hapi\hapi.exe，并把该目录加入 PATH。

确认 AI 助手命令可用

你只需要安装自己要用的 AI 工具：

5. 升级客户端

macOS Homebrew

brew update
brew upgrade hapi
hapi --version

手动安装的客户端

  1. 下载公司提供的新版本客户端。
  2. 停止 Runner：hapi runner stop。
  3. 替换旧的 hapi 或 hapi.exe。
  4. 执行 hapi --version 确认版本。
  5. 重新启动 Runner。

6. 初始化客户端

  1. 在 Web 中进入 Settings -> Account，复制你的个人 access token。
  2. 在终端中设置公司 HAPI Nexus 地址。
  3. 执行登录命令，按提示粘贴 token。
  4. 执行状态检查，确认登录成功。
export HAPI_API_URL="https://hapi.xthings.services"
hapi auth login
hapi auth status

也可以一次性运行：

HAPI_API_URL="https://hapi.xthings.services" \
CLI_API_TOKEN="<你的个人 access token>" \
hapi auth status
提示：默认 Hub 地址为 https://hapi.xthings.services。如果公司后续通知了新的地址，再按通知修改。

7. 运行我的电脑 Runner

Runner 是你电脑和 HAPI Web 之间的连接程序。启动后，Web 才能看到你的电脑，并在你允许的目录中启动 AI 任务。

选择允许访问的目录

--workspace-root 是你授权给 HAPI 使用的本地目录。建议选择包含多个项目的上级目录，例如：

hapi runner start --workspace-root /Users/yourname/Documents/projects

多个目录可以这样写：

hapi runner start \
  --workspace-root /Users/yourname/Documents/work \
  --workspace-root /Users/yourname/Documents/lab

常用命令

命令说明
hapi runner start --workspace-root <目录>启动 Runner，让 Web 可以使用该目录。
hapi runner status查看 Runner 是否在线。
hapi runner logs查看运行日志，排查连接问题。
hapi runner stop停止 Runner。
安全建议：不要把整个系统根目录作为 workspace root。只授权你希望 AI 读取和修改的工作目录。

8. 让 Runner 开机自动运行

如果你经常使用自己的电脑作为 HAPI 机器，建议把 Runner 加入系统服务。这样电脑开机并登录后，Runner 会自动启动，Web 端就能持续看到你的机器在线。

开始前请确认：先完成客户端初始化，并确认下面的命令可以手动运行成功。请把示例中的目录替换成你自己的工作目录。
HAPI_API_URL="https://hapi.xthings.services" \
hapi runner start --workspace-root /Users/yourname/Documents/projects
建议写入 HAPI_API_URL：如果你已经通过 hapi auth login 保存过登录信息，Runner 通常可以读取本地配置；但系统服务启动时环境变量可能和你的终端不同。为了避免服务启动后连错地址或找不到 Hub，建议在开机自动运行配置中明确写入 HAPI_API_URL=https://hapi.xthings.services。

macOS：使用 LaunchAgent

适合个人电脑。LaunchAgent 会在你登录 macOS 后自动启动 Runner。

mkdir -p ~/Library/LaunchAgents
cat > ~/Library/LaunchAgents/services.xthings.hapi-runner.plist <<'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>services.xthings.hapi-runner</string>
    <key>EnvironmentVariables</key>
    <dict>
        <key>HAPI_API_URL</key>
        <string>https://hapi.xthings.services</string>
    </dict>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/local/bin/hapi</string>
        <string>runner</string>
        <string>start</string>
        <string>--workspace-root</string>
        <string>/Users/yourname/Documents/projects</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
    <key>StandardOutPath</key>
    <string>/tmp/hapi-runner.log</string>
    <key>StandardErrorPath</key>
    <string>/tmp/hapi-runner.err</string>
</dict>
</plist>
EOF
launchctl load ~/Library/LaunchAgents/services.xthings.hapi-runner.plist

停止自动运行：

launchctl unload ~/Library/LaunchAgents/services.xthings.hapi-runner.plist

Linux：使用 systemd 用户服务

适合 Ubuntu、Debian 等 Linux 桌面或个人开发机。

mkdir -p ~/.config/systemd/user
cat > ~/.config/systemd/user/hapi-runner.service <<'EOF'
[Unit]
Description=HAPI Runner
After=network-online.target

[Service]
Type=simple
Environment=HAPI_API_URL=https://hapi.xthings.services
ExecStart=/usr/local/bin/hapi runner start --workspace-root /home/yourname/projects
Restart=always
RestartSec=5

[Install]
WantedBy=default.target
EOF
systemctl --user daemon-reload
systemctl --user enable --now hapi-runner.service

查看状态或停止：

systemctl --user status hapi-runner.service
systemctl --user stop hapi-runner.service

Windows：使用任务计划程序

适合 Windows 电脑。请先确认 hapi.exe 已放到固定目录，例如 C:\Tools\hapi\hapi.exe。

# 以 PowerShell 运行，按需修改路径
schtasks /Create /TN "HAPI Runner" /SC ONLOGON /TR "cmd /c set HAPI_API_URL=https://hapi.xthings.services&& \"C:\Tools\hapi\hapi.exe\" runner start --workspace-root \"C:\Users\yourname\Projects\"" /F

查看或删除任务：

schtasks /Query /TN "HAPI Runner"
schtasks /Delete /TN "HAPI Runner" /F
安全建议：自动启动时同样不要授权整个磁盘或系统目录。只把真正需要 AI 使用的项目目录作为 --workspace-root。

9. Web 端常用功能

会话列表

查看你自己创建或项目分享给你的 AI 会话。可以按项目、机器、目录筛选。

聊天详情

像聊天工具一样给 AI 发送任务，查看回复、命令输出、文件变更和待审批操作。

新建会话

选择 AI 类型、项目、机器和目录，输入任务说明，即可启动新的 AI 编程任务。

审批操作

当 AI 请求编辑文件、执行命令或访问敏感工具时，你可以在 Web 或手机上批准或拒绝。

账号设置

修改密码、查看个人 access token、退出登录、调整语言和界面风格。

项目共享

在你有权限的项目中查看成员、共享目录和会话，把 AI 工作过程沉淀到团队空间。

10. 如何创建会话

  1. 打开 Web，点击新建会话入口。
  2. 选择项目。如果只是个人使用，选择自己可用的项目；如果是团队协作，选择团队项目。
  3. 选择机器。机器可以是你自己的电脑，也可以是同事通过项目共享给你的机器。
  4. 选择工作目录。目录必须是该机器允许访问或项目共享的目录。
  5. 选择 AI 助手类型，例如 Claude、Codex、Cursor、Grok 或 OpenCode。
  6. 输入任务描述，例如“阅读这个模块并修复登录失败问题”。
  7. 点击创建，等待 AI 开始工作。

会话中可以做什么

  • 继续追问或补充需求。
  • 查看 AI 的中间过程、命令输出和工具调用。
  • 批准或拒绝需要确认的操作。
  • 给会话改一个更容易识别的名称。
  • 把会话归档，或后续重新打开继续处理。

11. 如何使用项目共享

项目是团队协作空间。你加入项目后，可以看到项目内共享的会话和目录。不同角色拥有不同权限。

角色你可以做什么适合场景
viewer查看项目会话和共享目录。了解进度、评审、旁观。
editor发送消息、创建会话、继续已有任务。项目成员日常协作。
admin管理项目成员和共享目录。项目负责人或模块负责人。
owner拥有项目最高管理权限。项目所有者。

加入别人分享的项目

  1. 使用你的公司账号登录 HAPI Web。
  2. 打开同事或负责人发送给你的邀请链接，或等待管理员把你添加到项目。
  3. 进入项目后，你会看到共享会话和可用工作目录。
  4. 如果你只有查看权限，需要创建或发送消息时请联系项目负责人提升角色。

把自己的项目分享给别人

  1. 确认你的电脑 Runner 已在线，并且目录已经加入项目 workspace。
  2. 进入 Settings -> Projects，找到目标项目。
  3. 在成员管理中搜索同事的用户名或显示名，选择角色并添加。
  4. 也可以生成邀请链接发给同事。
  5. 对方登录后即可看到该项目下的共享内容。

12. 如何同步 Codex 本地会话

如果你平时使用 OpenAI Codex CLI，本地会产生历史会话记录。HAPI 可以把这些本地历史导入到 Web 中，方便统一查看、继续对话和分享给项目成员。

注意：当前同步主要面向 Codex CLI 的本地历史。Codex 桌面客户端如果使用不同的本地存储格式，可能无法被当前同步功能直接导入。
  1. 确认你的电脑已经安装 Codex CLI，并且过去使用 Codex 处理过该目录的任务。
  2. 确认你的电脑 Runner 在线，且工作目录位于 Runner 授权目录内。
  3. 在 Web 中创建或打开 Codex 会话，选择对应项目、机器和工作目录。
  4. 点击 同步目录 或 导入 Codex 历史。
  5. 在弹窗中搜索并勾选需要导入的历史会话。
  6. 导入成功后，可以在 HAPI Web 中继续使用或分享。

13. 电脑端保存为桌面应用

你可以把 HAPI Web 保存成桌面应用，以后从 Dock、任务栏或开始菜单直接打开。

Chrome / Edge

  1. 在 Chrome 或 Edge 中打开公司 HAPI Nexus 网址。
  2. 点击地址栏右侧的安装图标。如果没有图标，打开右上角三点菜单。
  3. 选择 安装应用、安装 HAPI Nexus 或 将此页面安装为应用。
  4. 安装完成后，把图标固定到 Dock、任务栏或开始菜单。

macOS Safari

  1. 用 Safari 打开公司 HAPI Nexus 网址。
  2. 选择 文件 -> 添加到程序坞，或使用分享菜单里的添加选项。
  3. 确认名称后保存。

14. 手机端添加到主屏幕（不安装 App）

iPhone / iPad

  1. 使用 Safari 打开公司 HAPI Nexus 网址。
  2. 点击分享按钮。
  3. 选择 添加到主屏幕。
  4. 确认名称，点击 添加。
  5. 以后从主屏幕图标打开即可。
iOS 注意：请使用 Safari。iOS 上的 Chrome/Firefox 通常不能完成标准主屏幕安装。

Android

  1. 使用 Chrome 或 Edge 打开公司 HAPI Nexus 网址。
  2. 如果页面提示安装，点击 安装。
  3. 如果没有提示，打开右上角菜单，选择 添加到主屏幕 或 安装应用。
  4. 安装后从手机桌面图标打开。

手机上适合做什么

  • 查看 AI 任务是否完成。
  • 收到需要确认的操作时快速批准或拒绝。
  • 临时补充一句需求或追问。
  • 查看项目共享会话的最新进展。

15. 常见问题

1）我没有账号怎么办？

请联系平台管理员、团队负责人或项目负责人创建账号，或邀请你加入项目。

2）我只想查看项目，不写代码，需要安装 hapi 吗？

通常不需要。你只要用浏览器登录 Web 即可。只有当你希望平台使用你自己电脑上的代码目录时，才需要安装客户端并启动 Runner。

3）hapi: command not found 怎么办？

说明客户端没有安装好，或所在目录没有加入 PATH。macOS/Linux 可检查：

which hapi
hapi --version

4）Runner 启动后 Web 看不到我的机器

  • 确认 HAPI_API_URL 是公司 HAPI Nexus 地址。
  • 确认使用的是你自己的个人 access token。
  • 执行 hapi runner status 和 hapi runner logs 查看状态。
  • 确认公司网络、VPN 或代理没有阻断连接。

5）我可以把项目分享给没有源码的同事吗？

可以。源码保存在 Runner 所在机器上。对方登录 Web 后，只能按项目权限访问你共享的目录和会话。

6）为什么提示 Machine access denied？

通常是你没有该机器或项目目录的访问权限。请确认你已加入对应项目，并且项目已经挂载了该机器的 workspace。

7）为什么同步不到 Codex 本地会话？

  • 确认你同步的是 Codex CLI 历史，而不是桌面客户端专用历史。
  • 确认 Runner 与 Codex CLI 在同一台电脑、同一个系统用户下运行。
  • 确认该 Codex 历史的工作目录与 Web 中选择的目录一致。
  • 确认本机存在 ~/.codex/sessions 历史文件。

8）手机添加到主屏幕后总是要重新登录

请优先确认你使用的是同一个 HTTPS 域名，没有清理网站数据，没有在 IP 和域名之间来回切换。如果仍然出现，请反馈给平台管理员。

9）macOS 提示“hapi 已损坏，无法打开”

which hapi
sudo xattr -dr com.apple.quarantine "$(which hapi)"
sudo chmod +x "$(which hapi)"
hapi --version

10）我的 token 泄露了怎么办？

立即进入 Settings -> Account 重新生成个人 access token，并重启使用旧 token 的 Runner。
