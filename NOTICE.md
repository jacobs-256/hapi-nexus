- happy-cli derived code notice: [cli/NOTICE](cli/NOTICE)

## Modification Notice

This repository has been modified from upstream HAPI for the HAPI Nexus project.

Notable project-level changes include:

- private multi-user Web login with administrator-managed users
- per-user access token management
- scoped runner workspace browsing
- project sharing and membership management
- enterprise/private-deployment Web interface direction
- Markdown-only docs, with the VitePress docs site and marketing website removed
