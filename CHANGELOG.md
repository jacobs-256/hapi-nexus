# Changelog

All notable changes to HAPI Nexus should be documented in this file.

This project follows a pragmatic release log format. Add entries under `Unreleased` while developing, then move them under a version heading when publishing a release.

## Unreleased

- Storage architecture cleanup and documentation updates.

## 1.3.0

- Added client conversation import workflow groundwork.
- Added task history management in settings.
- Added global tool-disable controls for administrators.
- Improved settings and session layout.

## 1.2.0

- Split conversation storage and core data storage configuration.
- Added Elasticsearch conversation storage support.
- Added MySQL core data storage support.
- Added storage migration controls.
